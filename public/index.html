      How it works

      Step 01

      Pick a line

      Choose any number from the open list. It's shared and public — treat it like a payphone, not a mailbox.

      Step 02

      Use it to verify

      Paste the number into whatever site or app is asking for SMS verification.

      Step 03

      Watch it arrive

      The inbox polls automatically. The signal strip pulses while it checks, and messages appear the moment they land.

      Good to know

      Is this private?

      No. These are shared public numbers — anyone can request the same line and read the same inbox. Never use one for anything that matters long-term, like account recovery.

      How long does a number last?

      Availability depends entirely on the upstream provider. If a line stops receiving messages, just grab another one from the list.

      Do I need an account?

      No signup, no login. Open the page, pick a line, done.

      Can I send texts from it?

      No — this tool only receives. It's built for one-time codes and verification texts, not two-way messaging.
